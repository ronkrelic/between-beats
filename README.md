# Between Beats

A small light sees in heartbeats. A quiet browser game about memory as reconstruction: the room you remember is not quite the room you are in.

Continuity is not given. It is built.

## Play
https://ronkrelic.github.io/between-beats/

Desktop keyboard required.

- WASD / arrow keys: move
- Space: heartbeat
- E: keep a place / read / dismiss
- Esc: pause; at the end, sit in the light and view credits
- M: mute

No assets, no libraries, everything drawn and synthesized in code.
